개인정보 처리방침

시행일: 2026년 10월 29일

더그아웃 운영팀(이하 "운영자")는 더그아웃(이하 "서비스") 이용자의 개인정보를 개인정보 보호법에 따라 이렇게 다룹니다.

한눈에 보기

  • 서비스는 가입 · 로그인이 없고, 이름 · 이메일 · 전화번호 같은 개인정보를 받지 않습니다.
  • 고른 응원팀은 이 휴대폰에만 저장됩니다. 다만 잠금화면 점수 자동 표시를 켜면 응원팀 · 기기 무작위 번호 · 알림 토큰을 서버에 보관하고, 끄면 바로 지웁니다.
  • 이용 기록을 모으는 분석 도구와 광고를 쓰지 않습니다.

1. 휴대폰에만 저장하는 정보

  • 응원팀, 첫 실행 때 응원팀을 물어봤는지 여부, 잠금화면 실시간 점수 설정(켜고 끈 값), 앱이 이 기기에서 만든 무작위 번호
  • 앱을 지우면 함께 지워집니다. 설정 → 응원팀에서 언제든 바꾸거나 비울 수 있습니다.

2. 서버 접속 때 자동으로 남는 정보

경기 정보를 받아 오려고 서버에 접속할 때 IP 주소 · 접속 시각 · 요청한 주소가 서버 운영 업체의 접속 기록에 남을 수 있습니다.

  • 목적: 서비스 제공, 장애 대응, 부정 접속 차단
  • 근거: 개인정보 보호법 제15조 제1항 제6호(정당한 이익)
  • 보관: 서버 운영 업체의 기록 보관 기간이 지나면 자동으로 지워지며, 운영자가 따로 모으거나 이용자를 알아보는 데 쓰지 않습니다.

홈 화면 위젯을 쓰면 위젯이 응원팀 경기를 받아 오려고 응원팀 이름표(구단 id)를 서버에 보냅니다. 누구의 요청인지는 남기지 않습니다.

3. 잠금화면 점수 자동 표시를 켰을 때 보관하는 정보

앱 처음 실행 때 잠금화면 중계를 허용하거나 설정에서 응원팀 경기 자동 표시를 켜면, 앱을 열지 않아도 응원팀 경기 점수를 잠금화면에 띄우려고 아래 정보를 서버에 보관합니다. 켜지 않으면 보내지 않습니다.

  • 항목: 기기 무작위 번호(앱이 만든 값으로 이름 · 전화번호와 이어지지 않습니다), 응원팀, 알림 토큰(Apple 이 이 앱에 준 점수판 시작 주소)
  • 목적: 응원팀 경기의 잠금화면 · 다이내믹 아일랜드 점수판 자동 표시
  • 근거: 이용자의 동의(앱 처음 실행 때 또는 설정에서 허용)
  • 보관: 30일 동안 앱을 쓰지 않으면 자동으로 지웁니다. 설정에서 끄면 바로 지웁니다.

경기방에서 점수판을 직접 띄울 때는 그 경기의 공용 방송 채널로 점수를 받습니다. 이때는 이 기기의 정보를 서버에 보내지 않습니다.

4. 기기 권한

서비스는 위치 · 연락처 · 카메라 · 마이크 권한을 요청하지 않습니다. 경기 결과 카드를 사진에 저장할 때만 사진 추가 권한을 묻고, 사진 보관함의 사진은 읽지 않습니다.

잠금화면 중계를 허용하면 아이폰이 알림 허락을 묻고, 잠금화면 점수판을 처음 띄울 때 실시간 현황 허락을 묻습니다. 거절해도 다른 기능은 그대로 쓸 수 있습니다.

5. 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 따라 수사기관 · 법원이 요청하면 그 범위에서 제공할 수 있습니다.

6. 처리 위탁과 국외 이전

  • 서버 운영: Supabase Inc.(경기 정보 저장과 전송, 서버는 대한민국 서울 지역). 맡기는 것은 2항의 접속 기록과 3항의 자동 표시 정보입니다.
  • 잠금화면 점수 전송: Apple Inc.(미국)의 Apple 푸시 알림 서비스로 점수판을 띄우고 갱신합니다. 자동 표시를 켜면 3항의 알림 토큰이 점수판을 띄울 때마다 암호화된 통신으로 Apple 에 전달됩니다(국외 이전). 보관은 3항과 같고, 자동 표시를 끄면 이전이 멈춥니다.
  • 경기장 날씨: 경기방의 날씨를 보여 주려고 Open-Meteo(서버는 유럽)에 경기장 위치를 보내 날씨를 받습니다. 이때 휴대폰의 IP 주소가 그 업체에 전달될 수 있습니다.

7. 이용자의 권리

  • 서버에 보관한 자동 표시 정보는 설정 → 실시간 점수에서 응원팀 경기 자동 표시를 끄면 바로 지워집니다.
